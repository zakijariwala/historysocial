# Brand — @tariq.suhuf

Generated by `tools/build_social_logos.py` **in the noorpost repo**, which writes
into this directory. `--check` verifies without writing. The wordmark is outlines
cut from `fonts/SpaceGrotesk[wght].ttf`, so a hand edit is lost on the next
build. Open `contact-sheet.html` to see the set at working sizes.

**This is a separate git repository.** Commit `brand/` here, not in noorpost.

## Nothing here was invented

The palette and the face are this project's own, from `tokens/tokens.yaml` and
`fonts/`. A logo on a different palette from the feed it fronts is just a third
brand.

| | From |
|---|---|
| Ground `#EFEAE1` | `tokens.yaml` → `grounds.paper` |
| Ink `#25384E` | `tokens.yaml` → `inks.indigo` |
| Rust cut `#8A3A2A` | `tokens.yaml` → `inks.rust` |
| Night cut `#14161A` / `#C9C6C1` | `tokens.yaml` → `grounds.night`, `inks.bone` |
| Face | `fonts/SpaceGrotesk[wght].ttf`, pinned at wght 700 |

**Space Grotesk carries the wordmark, not EB Garamond**, and that is the main
thing keeping this account visually separate from the other two. It is the only
grotesque anywhere across the three projects — Noor Post is Fraunces,
@riwayah.daily is EB Garamond. `tokens.yaml` reserves the grotesque for "the
cover title box and nothing else"; the wordmark is the one addition, and it is a
cover title in everything but name.

**Watch the ground.** `paper #EFEAE1` and Noor Post's ivory `#F3EDE1` are four
hex points apart and will not be told apart by eye. The separation is doing its
work through ink and face, not ground — which is why the indigo and the
grotesque are not negotiable if you want these to read as different accounts.

## The mark

Suhuf — the sheets — as two stacked leaves, the front one carrying three lines of
text, a rule, and one short line beneath it.

That last line is the footnote, and it is the whole point. This account's rule is
that nothing reaches a slide without a printed page number behind it, so the
citation is the mark rather than an afterthought on it. The text gave up a fourth
line to make room for it: with four lines the rule and the footnote crowded into
the bottom of the leaf and the whole thing collapsed into a generic document icon
at feed size.

## Rules

- **Instagram crops profile pictures to a circle.** The avatar is built for it:
  full-bleed ground, nothing outside a radius of 78 in the 200-unit box. Do not
  add a square frame.
- **One ink per surface.** The five inks exist so a post names one; the same
  discipline applies here. Never indigo and rust together.
- No gradient, no shadow, no outer glow.
- The rust cut is for campaign use, not a second logo. Indigo is the account.

## Open

- **The handle spells `tariq`, the account is about `tarikh`.** *Tariq* is
  "path", or a given name; *tarikh* is "history". `tariq.suhuf` therefore reads
  as a person's name to anyone who knows the words. Flagged, not fixed — the
  filenames follow the handle as chosen. If the handle changes to
  `tarikh.suhuf`, rename the `slug` in `tools/build_social_logos.py` and rebuild;
  nothing else depends on it.
- **No raster exports.** SVG only. Instagram takes 320×320 for the avatar.
